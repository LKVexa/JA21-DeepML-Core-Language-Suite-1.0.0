
# Release Notes — JA21 DeepML Core Language Suite 1.0.0

## New standalone publication

- Reconstructed the uploaded 102-document corpus wrapper into its original DeepML Core source tree.
- Normalized all 10,000 examples into a compact technical corpus with explicit identity, pedagogy, source, AST, semantics, compiler, runtime, validation, provenance, and 8S sections.
- Published twenty 500-record corpus shards and a 10,000-row navigation index.
- Curated 1,000 source-faithful `.deepml` scripts with full topic/tier coverage and every certification record.
- Added a 22-chapter textbook, twelve-week curriculum, workbook, instructor guide, and starter project.
- Promoted grammar, compiler/runtime contracts, semantic operators, R12/MCRT schema, and conformance assets into a navigable standalone specification layer.
- Added offline inspection, structural validation, manifests, checksums, and Windows-safe paths.

## Compatibility

The source language identity remains `deepml.core` version `0.3`. Publication version 1.0.0 describes this standalone suite and does not imply a new native compiler version.

## Known limitation

Native compiler and runtime execution were not available for this build. Expected outcomes remain corpus-modeled until verified against a conforming implementation.
