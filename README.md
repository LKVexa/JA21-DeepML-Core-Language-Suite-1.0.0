# JA21-DeepML-Core-Language-Suite-1.0.0

Study tensors, model graphs, automatic differentiation, and schedules with JA21 DeepML Core. An offline suite joins 10,000 normalized records, 1,000 source examples, a 22-chapter textbook, and a twelve-week curriculum with grammar and runtime contracts. Explore language profile design and model toolchain research through explicitly modeled results.

The JA21 DeepML Core Language Suite organizes material for studying tensor types, model graphs, automatic differentiation, and execution schedules in the DeepML Core 0.3 profile. It gives students, educators, compiler authors, and model-language researchers a substantial source library and an inspectable set of language and evidence contracts.

Its primary assets are a 10,000-record normalized technical corpus, twenty navigable shards, 1,000 source-faithful .deepml examples, and a 22-chapter textbook. The collection spans 48 topics and six tiers, with positive, diagnostic, and certification records. A twelve-week curriculum, workbook, instructor guide, topic atlas, starter project, grammar, semantic operators, and compiler/runtime specifications support structured learning and implementation planning. Offline corpus tools and manifests help readers search, inspect, and verify the published data.

The updated audit validates schemas, source identity, policies, and consistency between master data and shards. It marks expected compiler and runtime outputs as modeled evidence and quarantines metadata conflicts. A native DeepML compiler and model runtime are not supplied, and complete grammar, parsing, shape inference, and execution conformance remain implementation work.

## Corpora and audit records

The supplied corpus layout is preserved under `payload/`. The `audit/` directory and [AUDIT_AND_UPGRADES.md](AUDIT_AND_UPGRADES.md) record source coverage, release changes, and evidence boundaries.

Historical source archives and source manifests remain provenance records. Current publication file hashes are listed in `PUBLICATION_SHA256.json`; licensing changes are recorded in `PUBLICATION_LICENSE_LEDGER.json`.
